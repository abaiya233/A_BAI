    新手教程

    从零到能聊天，一共五步。卡住了就看对应的那一步。

    1. 1
      装组件

      在「下载中心」的「QQ 机器人」里下载 SnowLuma 和 AstrBot。两个加起来约 320 MB，网速快的话一两分钟。MCS 是想开 Minecraft 服才需要，可以不装。

    2. 2
      启动大肥鱼

      回到第一个栏位点「启动大肥鱼」。它会依次开 SnowLuma、登录、拉起 QQ 进程、再开 AstrBot，每一步的进展都会实时显示，不用管它。

    3. 3
      QQ 扫码登一次

      第一次用要登录 QQ。点「打开 SnowLuma」，在新窗口里扫码，登录一次之后它会记住，以后不用再扫。

    4. 4
      给大脑接上模型

      点「打开 AstrBot 面板」，在「服务提供商」里填你的大模型 API Key（DeepSeek、OpenAI、通义都行），然后在「配置」里挑默认模型。不填 Key 的话机器人能上线但不会说话。

    5. 5
      去 QQ 找她说话

      以上都完成后，直接在 QQ 里给机器人账号发消息就行。没反应的话回来看「运行日志」里的报错。

    想换个电脑用？把整个工具箱文件夹复制过去，删掉 components/ 后重新下载组件即可。注意：snowluma/ 和 AstrBot 的数据里存着你的 QQ 登录凭据，别发给别人。
